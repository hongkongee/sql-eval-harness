# 키워드 추출 비교: 재파인튜닝 v2 (GLiNER v1 vs v2 vs LLM)

- 테스트셋: LLM으로 생성한 질의 100개. 정답 의료 컨셉 227개 중 학습 데이터에 있는 것은 하나도 없다.

## 요약

| 항목 | 지표 | 파인튜닝 GLiNER | LLM |
|---|---|---|---|
| 의료 컨셉 | 정밀도 (P) | 210 / 213 (98.6%) | 230 / 239 (96.2%) |
| 의료 컨셉 | 재현율 (R) | **208 / 227 (91.6%)** | 227 / 227 (100%) |
| 의료 컨셉 | F1 | 95.0 | 98.1 |
| 스키마 키워드 | F1 | 83.0 | 82.9 |
| 방문 유형·성별 | 맞힌 수 / 30 | 20 (66.7%) | 27 (90.0%) |
| 응답 속도 | 평균 / 중앙값 | 0.50초 / 0.51초 | 0.97초 / 0.88초 |

- **의료 컨셉:** 진단명·약물명·검사명·시술명 키워드.
  - **정밀도 (P):** 모델이 의료 컨셉으로 낸 것 중 실제 의료 컨셉인 비율
  - **재현율 (R):** 정답 의료 컨셉 중 모델이 의료 컨셉으로 찾아낸 비율
  - **F1:** 정밀도와 재현율의 조화평균
- **스키마 키워드 F1:** 환자·진단·처방·측정처럼 테이블을 가리키는 단어를 정확하고 빠짐없이 뽑았는지. 정답과 위치가 일부만 겹쳐도 맞힌 것으로 본다(예: 정답 "사망"을 "사망일"로, 정답 "입원"을 "재입원"으로 뽑은 경우).
- **방문 유형·성별:** 입원·외래·응급실, 남성·여성 정답 30개 중 값과 테이블까지 맞힌 개수
- **응답 속도:** 문장 하나 처리 시간(사내 서버 CPU, 순차 호출)
